## The problem

A client's web application was running on an aging codebase that was becoming increasingly expensive to maintain, with every change carrying outsized risk. It needed a modern, sustainable foundation without disrupting an Adobe AEM–driven content workflow already in place.

## What I built

I spearheaded the migration of the legacy codebase to React, modernizing the stack while keeping content authoring on Adobe AEM intact.

- Rebuilt the application's core screens in React, integrated with RESTful APIs for a clean separation between frontend and backend.
- Introduced Redux for state management, reducing bugs tied to inconsistent state handling.
- Championed the adoption of TypeScript across the team, which cut runtime errors by 25% and made the codebase meaningfully easier to maintain.
- Optimized components for consistent performance across a wide range of devices and browsers.

## Raising the bar for the team

Beyond the migration itself, I conducted over 100 code reviews to keep quality consistent as the codebase changed hands across the team, and mentored 15 junior developers through the transition to React and TypeScript — turning a stack change into a lasting shift in how the team worked.

## Outcome

The migration reduced maintenance overhead by 40% and left the team with a codebase — and a set of practices — built to keep evolving instead of accumulating risk.
